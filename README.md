# Fortune Magazine Fetcher

自动抓取 Fortune 杂志并生成 EPUB 文件。

## 功能

- 每周一自动抓取最新一期 Fortune 杂志
- 生成 EPUB 格式
- 支持手动触发指定期刊

## 使用方法

### 自动运行
每周一 UTC 0:00（北京时间周一早上 8:00）自动运行。

### 手动触发
1. 进入仓库 → **Actions**
2. 选择 **Fetch Fortune Magazine**
3. 点击 **Run workflow**
4. 可以选择输入指定的杂志归档 URL
5. 点击 **Run workflow**

## 下载结果

运行完成后，在 **Artifacts** 区域下载 EPUB 文件。
